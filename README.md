# DN1N — Doanh nghiệp một người

Văn phòng 3D theo phép chiếu trực giao, 12 Agent và chu kỳ ngày đêm 24 giờ. Giao diện tiếng Việt, chạy hoàn toàn trong trình duyệt.

Mở `index.html` để chạy. Không cần cài thư viện hoặc khóa API.

- Chọn avatar hoặc tên Agent để xem nhiệm vụ và SOP 6 bước.
- Phê duyệt hồ sơ hoặc yêu cầu làm lại; theo dõi bàn giao và báo cáo.
- Chọn tốc độ 1× / 60× / 300× / 1440×; kéo xoay và cuộn phóng to.
- Dữ liệu, chi phí và độ tin cậy hoàn toàn giả định; không kết nối AI hoặc dịch vụ thật.
- Chỉ chạy khi trang mở và hiển thị; tải lại sẽ khởi tạo phiên mới. Xuất JSON để giữ nhật ký.
- Kiểm tra logic: `node test.cjs`.

GitHub Pages: chọn Settings → Pages → Deploy from a branch → main / (root), nếu chưa bật.
